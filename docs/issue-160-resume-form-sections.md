# #160 생성 이력서 절 조립 작업 기록

## 목적

AI가 다시 쓴 문장을 줄바꿈으로만 나열하던 생성 결과를 확인된 이력서 양식의 절과 하위 항목으로 조립합니다. 근거 검사를 통과한 문장만 출력하고, 원문에 없는 절이나 항목 제목은 만들지 않습니다.

## 진행 방향

- 생성 결과의 절 조립은 `mcp/src/resume/output/runResumeHarness.ts`가 소유합니다.
- 절은 프로필, 학력, 경력, 인턴·대외활동, 교육, 자격증, 자기소개서, 포트폴리오, 취업우대사항, 희망근무조건, 지원분야 순서로 출력합니다.
- 추가 절을 생성할 때는 사용자가 선택한 XML 영역만 AI 입력에 포함하고, 근거 검사 이후 최종 본문에 배치합니다.
- 하위 항목은 `formItem`으로 지정합니다. 검사기는 항목 이름이 선택 원문 트리에 있고 원문 내용도 있을 때만 문장을 통과시킵니다. 같은 원소의 서로 다른 항목 문장은 각각 검사하며, 같은 항목에 충돌하는 문장은 기존처럼 충돌로 처리합니다.
- 자기소개서 항목은 선택 원문에 있는 제목 값과 일치할 때만 사용합니다.
- 기존 `render_resume_form` 출력과 `selectTemplateSections`의 템플릿 선택 동작은 유지합니다. 미리보기·선택 조회·템플릿 출력도 변경하지 않습니다.

## 결과

- 생성 결과에 확인된 절 제목을 붙이고 빈 절은 생략합니다.
- 경력 프로젝트는 XML 프로젝트 ID와 제목별로 문장을 묶어 프로젝트 이름 아래에 항목을 출력하며, 서로 다른 프로젝트의 근거를 한 문장에 합치면 누락으로 처리합니다.
- 프로필 필드와 프로젝트 하위 항목은 XML 원소 이름을 명시적으로 매핑합니다. 자기소개서의 자기소개, 성격의 장단점, 목표 및 포부는 원문 제목을 사용합니다.
- 추가 선택 영역은 기존 템플릿 선택 로직과 분리해 생성 경로에서만 읽습니다.
- `formItem`을 MCP 도구 입력 스키마에 선택 필드로 추가하고, 모델 재작성 요청에는 원문 값이 아닌 항목 구조만 전달합니다.
- 프로젝트 XML에 `technicalStructure`와 `projectApproach` 선택 필드를 추가했습니다. 원본 경력기술서의 프로젝트별 기술 설명과 업무 내용을 근거로 잡코리아 비즈센터, 알바몬 서비스 운영, 알바몬 MSA 구축, 한국후지필름 프로젝트의 값을 구성하고 원본 페이지 `sourceRefs`를 연결했습니다.
- 가격비교 플랫폼 프로젝트는 제공된 경력기술서에 해당 프로젝트의 구조·수행 방식이 없어 두 필드를 `status="missing"`으로 유지합니다.
- 두 XML 필드 이름을 각각 `기술적 구조`, `프로젝트 진행 방식` 하위 제목에 매핑했습니다. 내용이 있는 프로젝트는 근거 검사를 통과하면 해당 제목 아래에 출력합니다.
- 빈 문자열이나 공백만 있는 claim은 근거 검사에서 누락으로 처리하고 충돌 집계에서 제외합니다. 최종 이력서에 빈 절 제목이 생기지 않는 회귀 테스트를 추가했습니다.
- MCP `generate_resume` 로컬 도구의 결과 예시는 [resume-generation-example.md](./resume-generation-example.md)에 기록했습니다.
